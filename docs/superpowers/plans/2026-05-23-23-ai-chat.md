# AI chat multi-turn command surface

**Wishlist #:** 23 **Tier:** C **Wave:** 5 **Status:** queued
**Depends on:** Phase 0 ✓ (Yjs projection)
**Blocks:** #24 translate batch op reuses this chat infra.

## User-visible outcome

An Owner opens a chat panel in the editor, types natural-language requests ("make the hero section more dramatic", "add a testimonial row below the hero", "shorten all body copy"), and the Agent proposes changes one or more at a time. Each proposed change is previewed (existing Agent Edit preview pattern) and the Owner accepts or rejects. Multi-turn: the Agent remembers earlier requests in the session and references them. Stop-anytime mid-thought.

## Scope in

- Chat session state per (site, owner): kept in DO storage (SiteRoom) for ephemeral; persisted to DB on session end for retention.
- LLM tool surface = existing `src/agent/canvas-tools.ts` ops + a new `query_site` read-only tool so the Agent can inspect state.
- Multi-turn loop with system prompt referencing CONTEXT.md domain language.
- Preview-per-op pattern preserved: each tool call produces an op JSON that the editor previews; Owner accepts or rejects.
- Streaming responses to the chat panel via SSE on `/api/sites/:id/chat/stream`.
- Conversation pinned to one site; no cross-site memory.

## Scope out

- Tool calls that affect billing or external services.
- Agent-initiated publishes (Owner must publish manually).
- Image generation tool (gamma has this; out of POC scope unless follow-up).

## Contract with neighbors

- Reuses existing Agent preview pattern: tool calls produce ops; ops applied only on Owner accept.
- `query_site` returns a sanitised, token-bounded summary of current `EditableSite`.
- Session payload travels through the existing Gemini adapter.

## Smoke test

- `bun run chat:smoke`:
  - Mock LLM returns a 2-turn conversation that calls `query_site` then `propose_op`.
  - Asserts op preview produced, not auto-applied.
  - Accept → op applied via existing apply path; reject → state unchanged.

## Acceptance criteria

- Owner has a working chat panel.
- Multi-turn memory inside one session.
- All proposed changes previewable.
- All smokes green.
