# A11y audit subsystem

**Wishlist #:** 15 **Tier:** A **Wave:** 3 **Status:** queued
**Depends on:** Phase 0 ✓
**Blocks:** none

## User-visible outcome

When an Owner clicks Publish, the dashboard shows an accessibility report card with severity-tagged issues (e.g. "Hero image missing alt text", "Body text contrast 3.2:1 against background"). The Owner can publish anyway via a confirm, except when there are blocking issues — those must be fixed first. Each issue links to the offending element in the editor.

## Scope in

- Audit runner over current `editableState`:
  - Image / media alt text presence.
  - Text contrast (uses `src/theme/contrast.ts`) for every TextElement against its computed background.
  - Heading order (warn when a page jumps from H1 to H3 without H2).
  - Action element label presence (no empty buttons).
  - Form field labels (when #7 merged).
  - Page metadata title presence (when #21 merged).
- Severity ladder: `info` < `warning` < `blocking`.
- Configurable blocker list (default: missing alt on Media Element, contrast < 3.0 on body text).
- Pre-publish gate: API publish endpoint refuses with 422 listing blocking issues; Owner UI shows them.
- "Audit only" report endpoint independent of publishing.

## Scope out

- WCAG full conformance audit (POC covers a curated subset).
- Screen-reader walk-through simulation.
- Auto-fix suggestions.

## Schema delta

No tables. Audit results computed on demand.

## Contract with neighbors

- `runAudit(state): AuditReport` returns array of `{ kind, severity, elementId, pageSlug, message, fixHint }`.
- Publish path imports `runAudit`; refuses on `blocking` count > 0 with structured 422.

## Smoke test

- `bun run a11y:smoke`:
  - Fixture page with missing alt → reports blocking issue.
  - Fixture page with text contrast 2.5 → blocking.
  - Clean fixture → empty report.
  - Heading H1 → H3 → warning issue.

## Acceptance criteria

- Owner publishing a problematic site sees blocking errors and cannot publish.
- After fix, publish succeeds.
- Report endpoint returns same issues independently of publish.
- All smokes green.
