# SEO meta + page metadata

**Wishlist #:** 21 **Tier:** B **Wave:** 3 **Status:** queued
**Depends on:** Phase 0 ✓ (`CanvasPage` SEO fields scaffolded)
**Blocks:** #22 sitemap reads these fields.

## User-visible outcome

An Owner sets a page title, description, and social preview image per page (or uses generated OG from #6). The Published Site emits proper `<title>`, meta description, Open Graph + Twitter Card tags, canonical URL, and an optional `noindex` toggle. Sharing the page on Slack / Twitter / LinkedIn shows a proper unfurl card.

## Scope in

- Per-page metadata in `CanvasPage`: `title?`, `description?`, `ogImageAssetId?`, `canonical?`, `noIndex?`, `locale?` (Phase 0).
- Public renderer emits in `<head>`:
  - `<title>` — page title || site name.
  - `<meta name="description">`.
  - Open Graph: `og:title`, `og:description`, `og:image`, `og:url`, `og:type`.
  - Twitter: `twitter:card=summary_large_image`, `twitter:title`, `twitter:description`, `twitter:image`.
  - `<link rel="canonical">` from `canonical` or page URL.
  - `<meta name="robots" content="noindex">` when `noIndex` is true.
  - `<html lang="...">` from `locale` (defaults to site default locale).
- Editor: SEO panel in page settings.
- OG image precedence: explicit `ogImageAssetId` > generated via #6 > none.

## Scope out

- Schema.org structured data (JSON-LD) — keep simple.
- Per-page locale routing (handled by #25).
- Editing meta via AI (could be a #23 follow-up).

## Smoke test

- `bun run seo:smoke`:
  - Page with title + description → meta tags present.
  - `noIndex: true` → robots meta emitted.
  - With `ogImageAssetId` → og:image points to `/assets/<contentHash>`.
  - Without → falls back to `/og/<siteId>/<pageSlug>.png` if #6 available.
  - HTML entities in title escaped correctly.

## Acceptance criteria

- Owner sets title/description; view-source shows expected meta.
- Social unfurl renders.
- All smokes green.
