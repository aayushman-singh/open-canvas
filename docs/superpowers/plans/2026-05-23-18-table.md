# Table primitive

**Wishlist #:** 18 **Tier:** B **Wave:** 4 **Status:** queued
**Depends on:** Phase 0 ✓ (`table` ElementType stub)
**Blocks:** none

## User-visible outcome

An Owner drops a Table Element, fills column headers and rows, publishes. Visitors see a clean table styled with the site's Style Kit — zebra stripes, sensible padding, mobile-collapse for narrow viewports (collapses each row into a stacked card on phone breakpoint).

## Scope in

- New ElementType `table` with `columns: { id, header }[]` and `rows: { id, cells: Record<columnId, string> }[]`.
- Editor: data grid with add column / add row, drag to reorder, cell text edits.
- Renderer: semantic `<table>` with `<thead>`, `<tbody>`, `<th>`, `<td>`.
- Responsive (Wave 1 #1 contract): phone breakpoint collapses to stacked rows using `data-label` attributes and CSS `display: block`.
- Style: borders, padding, zebra rows pulled from Style Kit tokens.

## Scope out

- Cell formatting beyond plain string (no markdown / inline formatting; that's `TextElement` territory).
- Sorting / filtering / pagination (static table only).
- Cell merge / spans.
- Importing CSV/Excel.

## Schema delta

Phase 0:

```ts
// src/canvas/elements/table.ts
export interface TableElement extends BaseElement {
  type: 'table';
  columns: Array<{ id: string; header: string }>;
  rows: Array<{ id: string; cells: Record<string, string> }>;
  zebra: boolean;
  collapseOnPhone: boolean;
}
```
