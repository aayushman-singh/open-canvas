# Embed primitive

**Wishlist #:** 8 **Tier:** A **Wave:** 2 **Status:** queued
**Depends on:** Phase 0 ✓ (`embed` ElementType stub)
**Blocks:** none

## User-visible outcome

An Owner pastes a URL — YouTube video, Figma file, Loom, Google Map, Airtable view — into an Embed Element. The editor previews the embed inline. On the Published Site, Visitors see the third-party content rendered safely in an iframe.

## Scope in

- New ElementType `embed`: URL field + optional title + optional aspect ratio.
- oEmbed resolver: for known providers (YouTube, Vimeo, Loom, Figma, Spotify, SoundCloud, CodePen, Twitter/X), parse URL into embed iframe URL + dimensions. Server-side resolution, cached.
- Generic iframe fallback for arbitrary URLs — sandboxed.
- CSP discipline: published site sets `Content-Security-Policy` with explicit `frame-src` allowlist per resolved embed.
- iframe attributes: `sandbox="allow-scripts allow-same-origin allow-popups allow-forms"`, `referrerpolicy="no-referrer"`, `loading="lazy"`.

## Scope out

- Native rich-preview cards (link preview with screenshot) — separate feature.
- Server-side proxy of third-party content (bandwidth + legal hot potato).
- Resizable embeds beyond fixed aspect ratio.

// src/canvas/elements/embed.ts (Phase 0 stub, filled in here)

## Contract with neighbors

- Published renderer reads embed elements, builds iframe with sandboxed attributes.
- `buildEmbedCsp(snapshot): string` returns the full CSP header value for the snapshot.

## Smoke test

- `bun run embed:smoke`:
  - YouTube URL resolves to `https://www.youtube.com/embed/<id>`; asserts iframe src.
  - Unknown URL renders generic iframe with sandboxed attrs.
  - CSP for snapshot containing YouTube + Loom includes both `frame-src` origins.
  - oEmbed cache returns cached result on second lookup.

## Acceptance criteria

- Owner pastes YouTube link → preview shows in editor + Published Site.
- View-source on Published Site shows correct sandboxed iframe + CSP header.
- All smokes green.

## Open questions

- Whether to allow `<script>` execution inside embed iframe — sandboxed `allow-scripts` enables it but blocks `allow-same-origin` when combined for known cross-site frames. Recommend keeping both for embeds since third-party providers expect it; the sandbox + CSP `frame-src` allowlist is the protection.
