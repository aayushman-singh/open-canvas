# OG image generation at edge

**Wishlist #:** 6  **Tier:** S  **Wave:** 1  **Status:** queued
**Depends on:** Phase 0 ✓ (asset pipeline #2 done in Phase 0; SEO field `CanvasPage.ogImageAssetId`)
**Blocks:** #21 SEO meta uses generated OG URL when no manual override.

## User-visible outcome

When a Visitor shares a Published Site link on a chat app or social network, the unfurled preview shows a branded card — the site's headline, a tagline, and the site's Style Kit colours, even if the Owner never uploaded a custom OG image. Owners who do upload a custom OG image see that one instead.

## Scope in

- Edge endpoint `GET /og/:siteId/:pageSlug.png` that renders a 1200×630 PNG.
- Renderer uses Satori (wasm) to convert a JSX tree to SVG, then resvg-wasm to rasterise to PNG.
- Card layout pulls page title, optional description, site Style Kit tokens (background, accent, fontFamilyDisplay).
- Caching: response sets `Cache-Control: public, max-age=3600`; underlying R2 stores rendered PNG at `og/<siteId>/<pageSlug>.png` keyed by snapshot version so stale never served.
- On publish: enqueue OG render for every page; populate `CanvasPage.ogImageAssetId` with the generated asset.
- Custom override: when Owner uploads an image and sets it on the page, that asset takes precedence.

## Scope out

- Animated previews (Twitter player card).
- Multiple OG variants per page (Twitter vs Facebook custom sizing).
- Auto-screenshot of full rendered page (chromeless headless browser — out of POC scope).

## Files read-only (must not modify)

- `src/canvas/schema.ts`, `src/db/schema.ts`.
- `src/assets/*` (consume only).

## Contract with neighbors

- Reads `siteAsset` via R2 client when Owner has a custom override (`page.ogImageAssetId` set).
- Reads `site.editableState.styleKit` to fetch token values.
- Returns 302 to `/assets/<contentHash>` when Owner-provided custom image exists.
- Otherwise streams PNG bytes from R2 cache (or renders + stores then streams).

## Smoke test

- `bun run og:smoke`:
  - Renders a default card from fixture site state; asserts PNG bytes > 0, dimensions 1200×630.
  - Asserts cache hit on second call (R2 `head` succeeds).
  - With `page.ogImageAssetId` set to a real asset, asserts 302 to that asset URL.

## Acceptance criteria

- `/og/:siteId/:pageSlug.png` returns valid PNG.
- Card shows page title in Style Kit display font, Style Kit accent on background.
- Social unfurl (manual check via debugger like opengraph.xyz) shows generated card.
- All smokes green.
