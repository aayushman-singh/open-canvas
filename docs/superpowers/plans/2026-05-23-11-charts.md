# Charts primitive

**Wishlist #:** 11  **Tier:** A  **Wave:** 2  **Status:** queued
**Depends on:** Phase 0 ✓ (`chart` ElementType stub)
**Blocks:** none

## User-visible outcome

An Owner adds a Chart Element to a section, picks a chart kind (bar, line, pie, donut, area), pastes or hand-types simple tabular data, and immediately sees a styled chart on the canvas using the site's Style Kit colours. Visitors see the same chart rendered as SVG (no client JS).

## Scope in

- New ElementType `chart` with: `kind` (bar/line/pie/donut/area), `series` (labels + numeric data), optional `xAxis` / `yAxis` titles, optional legend toggle.
- Server-rendered SVG via a tiny chart helper (no heavyweight lib like recharts; pure SVG math).
- Style: chart colours derived from current Style Kit accent + variants.
- Editor UI: data grid (rows + columns), kind picker, axis title fields, legend toggle.
- Width/height respect Positioned Element box.

## Scope out

- Interactive tooltips on hover (no JS in published bundle).
- Real-time data sources (fetch from URL). Static data only.
- Advanced chart kinds (Gantt, funnel, scatter) — keep to 5 core kinds.

## Schema delta

Phase 0 stub at `src/canvas/elements/chart.ts`:

```ts
export interface ChartElement extends BaseElement {
  type: 'chart';
  kind: 'bar' | 'line' | 'pie' | 'donut' | 'area';
  series: Array<{ label: string; values: number[] }>;
  categories: string[];          // X-axis labels for bar/line/area
  xAxisTitle?: string;
  yAxisTitle?: string;
  showLegend: boolean;
}
```
