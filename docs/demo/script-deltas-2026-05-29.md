## Cross-cutting "+ New Page" finding

The "+ New Page" button at the bottom of the Pages sidebar:

- Creates a page **immediately** with no input modal
- Auto-names it `Page N` where N is a sequence counter
- After create, Maya must Rename it (only edits title, not slug)
- Delete confirmation modal: title "Delete page" + body "Delete page \"{name}\"? This cannot be undone." + Cancel/Delete buttons (no type-the-name gate, unlike Delete-site)

This affects S4.C (add `manifesto` via agent — still uses agent, but for manual page-add the flow is different) and I4.B (no locale picker at create time).
